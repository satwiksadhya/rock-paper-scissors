Rock Paper Scissors (Console Game)

How to Play

This game is played entirely in the browser console. You will play against the computer for 5 rounds.

Game Flow

  1. Open your browser.

  2. Open the Console

    Use one of these shortcuts to open the browser console:

    • Windows / Linux: Press F12 or Ctrl + Shift + J
    • Mac: Press Cmd + Option + J

    Then click on the Console tab if it's not already open.

  3. Refresh the Browser while the console is opened to run the game.
  4. You will see a prompt asking for your move.
  5. Enter one of the following:
    • rock
    • paper
    • scissors
  6. The computer will randomly choose its move.
  7. The result of the round will be shown in the console.

Rounds

The game runs for exactly 5 rounds. You will see the prompt appear 5 times — once for each round.

Winning Rules

  • Rock beats Scissors
  • Scissors beats Paper
  • Paper beats Rock

Scoring

  • Your score increases when you win a round.
  • The computer score increases when it wins.
  • Scores are displayed in the console after each round.

Game Result

After 5 rounds:

  • The final scores are displayed.
  • A winner is घोषित (You or Computer).

Technical Notes

  • The game uses prompt() for input.
  • The computer choice is generated using Math.random().
  • The game logic runs entirely in JavaScript.
